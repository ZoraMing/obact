  1. 原版
  2. 改 id：所有 id 换新命名
  3. 改文案：按钮、标签、占位符文字都改
  4. 改层级：多套几层容器、分组、折叠区
  5. 移动位置：元素换位置；按位置编号的工具栏 id 指向了别的按钮（冲突）
  6. id 挪用：两对元素互换 id（冲突）
  7. 全面改版：id、文案、类名、name、链接全改（两类定位器都失效）
