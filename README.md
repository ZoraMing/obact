# Obact

Obact（暂定名）：本地运行、跨平台的浏览器识别与操作工具。把网页整理成可选择的操作和页面内容，按 JSONL 工作流带检查、可续跑地执行。第一阶段不接入 AI，目标是给以后的 AI 提供可靠的“眼睛和手”。
